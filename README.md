مدير تحميل متعدد الاتصالات (زي IDM) + إضافة كروم تلتقط روابط التحميل والفيديو من الصفحة.

## المكونات

- `core/` — محرك التحميل: تحميل مجزأ متعدد الاتصالات مع استئناف، وتحميل HLS (m3u8) بدمج الأجزاء عبر ffmpeg.
- `app/` — واجهة سطح المكتب (Electron).
- `bridge/` — سيرفر محلي (WebSocket على 127.0.0.1) يربط إضافة كروم بالبرنامج.
- `extension/` — إضافة كروم (Manifest V3).
- `cli/` — أدوات اختبار من سطر الأوامر.

## المتطلبات

- Node.js 18+
- ffmpeg متاح في PATH (مطلوب فقط لتحميل فيديوهات HLS)

## التشغيل

أسهل طريقة: اضغط دبل كلك على [run.bat](run.bat) — يفحص وجود Node.js و ffmpeg، يثبّتهم تلقائياً عبر winget إذا كانا ناقصين، يثبّت مكتبات المشروع أول مرة، ثم يشغّل البرنامج.

أو يدوياً:

```bash
npm install
npm start
```

هذا يفتح نافذة البرنامج ويشغّل السيرفر المحلي (الجسر) تلقائياً.

## ربط إضافة كروم

1. افتح `chrome://extensions`، فعّل "وضع المطور"، ثم "تحميل غير مُحزّم" (Load unpacked) واختر مجلد `extension/`.
2. افتح البرنامج، اضغط "ربط إضافة كروم" لعرض المنفذ (Port) والمفتاح (Token).
3. افتح أيقونة الإضافة في كروم، الصق المنفذ والمفتاح، واضغط "حفظ والاتصال".
4. بعد الربط، أي رابط تحميل تضغطه في كروم يُرسل تلقائياً للبرنامج بدل تحميل كروم الافتراضي. وفوق أي فيديو في الصفحة يظهر زر ⬇ يعرض الجودات المتاحة والترجمات.

## الاختبار من سطر الأوامر (بدون واجهة)

```bash
node cli/download.js <رابط> [مسار_الحفظ] [عدد_الاتصالات]
```

## ملاحظات مهمة

- **الاستئناف**: البرنامج يحفظ تقدم كل جزء في ملف `<اسم_الملف>.ddl.json` بجانب التحميل. لو انقطع التحميل (إغلاق البرنامج، انقطاع كهرباء)، إعادة تشغيل نفس التحميل يكمل من حيث توقف، لا يبدأ من الصفر.
- **الأمان**: السيرفر المحلي (bridge) يستمع فقط على `127.0.0.1` (غير قابل للوصول من الشبكة)، ولا يقبل أي أمر بدون المفتاح (Token) الصحيح.
- **الحدود**: هذه الأداة مصممة للتحميل المشروع (ملفات مشاريعك، فيديوهات HLS/DASH غير محمية بـ DRM). لا تدعم ولن تُطوَّر لتجاوز حماية DRM (نتفليكس، شاهد، آبل تي في، إلخ).
