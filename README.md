مدير تحميل متعدد الاتصالات (زي IDM) + إضافة كروم تلتقط روابط التحميل والفيديو من الصفحة.

## المكونات

- `core/` — محرك التحميل: تحميل مجزأ متعدد الاتصالات مع استئناف، وتحميل HLS (m3u8) بدمج الأجزاء عبر ffmpeg.
- `app/` — واجهة سطح المكتب (Electron).
- `bridge/` — سيرفر محلي (WebSocket على 127.0.0.1) يربط إضافة كروم بالبرنامج.
- `extension/` — إضافة كروم (Manifest V3).
- `cli/` — أدوات اختبار من سطر الأوامر.

## المتطلبات

- Node.js 18+
- ffmpeg متاح في PATH (مطلوب فقط لتحميل فيديوهات HLS)

## التشغيل

أسهل طريقة: اضغط دبل كلك على [run.bat](run.bat) — يفحص وجود Node.js و ffmpeg، يثبّتهم تلقائياً عبر winget إذا كانا ناقصين، يثبّت مكتبات المشروع أول مرة، ثم يشغّل البرنامج.

أو يدوياً:

```bash
npm install
npm start
```

هذا يفتح نافذة البرنامج ويشغّل السيرفر المحلي (الجسر) تلقائياً.

## ربط إضافة كروم

1. افتح `chrome://extensions`، فعّل "وضع المطور"، ثم "تحميل غير مُحزّم" (Load unpacked) واختر مجلد `extension/`.
2. شغّل البرنامج — الإضافة تتصل به تلقائياً على `ws://127.0.0.1:9333`، بدون أي منفذ أو مفتاح تنسخه يدوياً. أيقونة الإضافة تعرض "Connected to app ✓" عند نجاح الاتصال.
3. بعد الربط، أي تحميل في كروم من الأنواع الموجودة في قائمة البرنامج (Options → File Types) يُرسل تلقائياً للبرنامج، وباقي الأنواع تبقى مع كروم — مثل IDM. نوع الملف يُعرف من الاسم الذي حدّده السيرفر، أو امتداد الرابط النهائي، أو نوع المحتوى (فرابط `download.php` الذي يرسل ZIP يُعامل كـ ZIP). أي تعديل على القائمة يصل للإضافة فوراً، ونافذة الإضافة تعرض عدد الأنواع الملتقطة. للإجبار على تحميل أي ملف بالبرنامج استخدم مفتاح Force. وفوق أي فيديو في الصفحة يظهر زر ⬇ يعرض الجودات المتاحة والترجمات.
4. ما يبقى مع المتصفح عمداً: ملفات `blob:` و`data:` التي تولّدها الصفحة نفسها، والتحميلات الناتجة عن نموذج POST — لأن البرنامج لا يستطيع إعادة طلبها. واضغط Alt أثناء النقر لترك أي تحميل للمتصفح.

## الاختبار من سطر الأوامر (بدون واجهة)

```bash
node cli/download.js <رابط> [مسار_الحفظ] [عدد_الاتصالات]
```

## الاختبارات

```bash
npm test
```

يشغّل كل ملفات `test/*_test.js` (كل ملف في عملية منفصلة) ضد سيرفرات محلية — بدون إنترنت. الاختبارات التي تحتاج ffmpeg (HLS/DASH الحقيقية) تُعلَّم `SKIP` إن لم يكن مثبتاً. اختبارات `npm run test:integration` تستخدم الإنترنت فعلاً ولا تدخل في `npm test`.

## ملاحظات مهمة

- **الاستئناف**: البرنامج يحفظ تقدم كل جزء في ملف `.ddl.json` داخل مجلد الملفات المؤقتة (Options → Save To → Temporary folder)، أو بجانب التحميل إن لم يُحدَّد مجلد مؤقت. لو انقطع التحميل (إغلاق البرنامج، انقطاع كهرباء)، إعادة تشغيله يكمل من حيث توقف. وإن تغيّر الملف على السيرفر أثناء التوقف، يعيد البرنامج تحميله من البداية بدل خلط النسختين.
- **الملف لا يظهر في مجلدك إلا مكتملاً**: التجميع يتم في المجلد المؤقت، والملف يُنقل لمكانه النهائي فقط بعد التحقق من حجمه. وإن وُجد ملف بنفس الاسم يُحفظ الجديد باسم `name (2).ext` بدل الكتابة فوق القديم.
- **الأمان**:
  - السيرفر المحلي (bridge) يستمع فقط على `127.0.0.1`، ويقبل الاتصال من إضافات المتصفح (`chrome-extension://` / `moz-extension://`) أو من برامج محلية فقط. أي صفحة ويب — بما فيها الـ iframe المعزول الذي يرسل `Origin: null` — تُرفض.
  - لا تخرج كلمات مرور Site Logins أو البروكسي من البرنامج أبداً، ولا يستطيع أي عميل تحديد مسار الحفظ؛ المسار قرارك أنت داخل البرنامج.
  - الكوكيز وبيانات الدخول تُرسل فقط للموقع الذي أُخذت منه، لا لأي CDN آخر.
  - أسماء الملفات القادمة من السيرفر تُنظَّف، فلا يمكن لاسم مثل `..\..\Startup\x.bat` الخروج من مجلد التحميل.
  - ملف PAC للبروكسي يعمل في بيئة معزولة لا تصل لـ Node.
- **الحدود**: هذه الأداة مصممة للتحميل المشروع (ملفات مشاريعك، فيديوهات HLS/DASH غير محمية بـ DRM). لا تدعم ولن تُطوَّر لتجاوز حماية DRM (نتفليكس، شاهد، آبل تي في، إلخ). بروتوكول FTP غير مدعوم حالياً، والبث المباشر (Live) لا يُسجَّل.
